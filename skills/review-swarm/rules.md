# Rules for judging findings

Validators read this file before every verdict; reviewers read it before they start. The supervisor
adds each owner decision here as soon as it is made, with the date. A finding that only repeats an
entry is rejected (INVALID, citing the entry) unless it brings a genuinely new angle or a concrete
exploit.
